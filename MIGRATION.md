# Migration checklist

Assembling this repository from the `fc_group/` subdirectory of the `llm-perception`
working tree. Source paths below are relative to that `fc_group/`.

Nothing is moved or deleted at the source -- every step is a copy followed by a path
rewrite. The source tree stays intact until the end-to-end check at the bottom passes.

**Excluded from the release**, deliberately:

| | |
|---|---|
| `rag/`, `scripts/rag/` | Untracked in the source repo, never committed. A work-in-progress track, not a released result. |
| `PROBE_NOTES.md` | Gitignored methodology notes, 36 KB. Kept local. |
| `Results/`, `Results_old/`, `Results_old2/` | 12 GB of generated output. The committed reproducibility layer is `analysis/*/data/*.csv`. |
| `activation_datasets_functional_groups/` | 1.1 GB of saved tensors. Regenerated by extraction. |
| `Analysis/visuals/**/*.png` | Rebuilt from the snapshot CSVs by `make_visuals*.py`. |

## Every copied file needs the canonical import stanza

Replacing whatever `HERE` / `REPO` / `FC` computation and `sys.path.insert` lines it
currently carries. Root goes on the path first so `paths` is importable, then `paths.SRC`
for the flat sibling imports the code already relies on.

```python
import os
import sys
sys.path.insert(0, os.path.abspath(os.path.join(os.path.dirname(os.path.abspath(__file__)), '..')))
import paths                       # noqa: E402
sys.path.insert(0, paths.SRC)      # noqa: E402
```

`'..'` for files in `src/`; `'..', '..'` for files in `analysis/<topic>/`. Fifteen source
files already carry a variant of this shape, so it normalizes rather than introduces.

## Done when

No GPU, no `results/`, no external .tex clone:

```bash
python analysis/paper/check_claims.py && echo OK
```

It reads only `analysis/*/data/*.csv` and asserts the numbers the paper's argument rests
on. Exit 0 proves the migration preserved both the snapshot CSVs and the code that reads
them. Capture the same command's output in the source tree first -- that is the reference
to diff against.

A grep for the old layout should come back empty:

```bash
grep -rn "fc_group" . --include='*.py' --include='*.sh' --include='*.sbatch' --include='*.md' | grep -v MIGRATION.md
```
